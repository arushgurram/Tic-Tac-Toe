# 🎮 CustomTkinter Tic-Tac-Toe

A modern, desktop Tic-Tac-Toe game built in Python using **CustomTkinter**. Features automatic window centering, dynamic turn tracking, winner detection with row highlighting, PyInstaller icon resource path handling, and single-click restart capabilities.

## ✨ Features

- **Modern UI:** Built with CustomTkinter for sleek dark-mode aesthetics[cite: 5].
- **Auto-Centered Window:** Automatically calculates your screen dimensions and places the game window in the exact center upon launch[cite: 5].
- **Highlighting Logic:** Automatically highlights winning tiles in orange (`#FB8500`) when a player gets three in a row[cite: 5].
- **Dynamic Status Display:** Tracks active player turns, win declarations, and ties in real-time[cite: 5].
- **Standalone Build Support:** Includes `resource_path()` helper to easily bundle assets into executable files via PyInstaller[cite: 5].
